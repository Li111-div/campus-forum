# 验收清单

> 配套文档：[设计方案.md](./设计方案.md)
> 用法：每完成一个里程碑，把对应章节的复选框勾掉。**没勾完不进下一阶段**（旧项目就是在「边做边加需求」上崩的）。

---

## 通用约定

每个功能的验收都看三件事，缺一不算通过：

1. **正常路径**：功能能用；
2. **异常路径**：网络失败 / 权限不足 / 数据为空时，界面有明确提示，不白屏、不吞错；
3. **越权路径**：换一个普通账号或未登录状态，**直接调接口**（不走前端按钮），确认被数据库拦住。

> 第 3 条最重要。前端隐藏按钮不算验收通过。
