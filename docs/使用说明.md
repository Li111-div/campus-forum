## 访问规则（未登录先去登录页）

- 未登录时打开任何地址（首页 / 帖子 / 个人中心 / 发帖…）都会**先进入登录/注册页**，登录成功后自动回到原页面；
- 唯一例外是「社区规则」页（`/#/rules`），不登录也能看；
- 浏览器会记住登录状态（存 localStorage），刷新不用重新登录；**换浏览器、换访问地址（比如从 localhost 换成局域网 IP）需要重新登录一次**；
- 如果 20 秒内连不上 Supabase，页面会显示「网络连接超时」并提供重试按钮（不会一直转圈）。

## 日常使用

| 想做的事 | 在哪 |
|---|---|
| 发帖 | 右上角「发帖」，选板块、写标题和正文 |
| 看帖/评论/点赞/收藏 | 点帖子标题进入详情 |
| 按时间筛选帖子 | 首页「时间」一行：不限时间 / 今天 / 近 3 天 / 近 7 天 / 近 30 天，或点「自定义」选两个日期后点「应用」；筛选条件会写进地址栏，刷新或分享链接都保持 |
| 回复某条评论 | 在评论右侧点「回复」，输入后发送（会通知被回复的人） |
| 给评论点赞 | 评论右上角的 👍「赞」按钮，点一次 +1，再点一次取消；刷新后状态保留 |
| 违禁词拦截 | 发帖标题/正文、评论、昵称、用户名里含违禁词会被拒绝并提示「包含违禁词「xx」」；管理员可在「管理后台 → 违禁词」增删词条 |
| 意见反馈 | 侧边栏「意见反馈」提交建议 / 问题 / 其他，可留联系方式；提交后能在「我的反馈」看到进度，管理员处理后会变为「已处理」 |
| 修改密码 | 个人中心 →「修改密码」：先验证当前密码，再设新密码；改完其它设备会被登出 |
| 找回密码 | 登录页「忘记密码？」→ 输入邮箱 → 点邮件里的重置链接 → 设置新密码（链接只能用一次，过期需重新发送） |
| 好友 | 侧边栏「好友」→「找人」搜昵称（至少 2 字）→「加好友」；对方在「好友申请」同意后成为双向好友。可删除好友或拉黑（拉黑后对方无法发私信） |
| 发帖带图片 | 发帖页「图片（可选）」区域点「添加图片」或把图片拖进去，可传 4 张、单张 8MB 以内；上传完成后点发布，卡片显示首图，详情页点图看原图 |
| 数据备份 | 运维用脚本：`npm run db:export` 导出一份快照（JSON/CSV + manifest 校验和），`npm run db:export:verify <目录>` 校验备份是否完整 |
| 实时推送 | 通知与私信走 WebSocket 即时到达，不用手动刷新；侧边栏底部显示「实时推送已连接」，断线时自动改用轮询 |
| 私信 | 侧边栏「私信」或好友行的「私信」按钮进入；只有双向好友能发消息，3 秒轮询近实时到达；删好友后历史仍可看但不能发 |
| 我的帖子/评论/收藏/关注/粉丝 | 右上角头像 → 个人中心 |
| 修改昵称、头像、简介 | 个人中心 → 「编辑资料」：头像可**自选图标（180+ 个 emoji）+ 背景（20 套渐变，或用取色器自定义两个颜色）** |
| 处理举报、置顶/锁帖/删帖、封禁用户 | 头像菜单 → 管理后台（需先设管理员）。举报列表里点「查看被举报评论 / 查看被举报帖子」可直接跳到原帖，评论会自动滚动并高亮 |
| 改发帖限制 | Supabase SQL Editor 改 `app_config` 表，如 `post_daily_limit` |

> **未读通知怎么看出来：** 有未读通知时，顶栏铃铛、左侧「通知」菜单右侧、手机底部导航「通知」上都会出现**红色数字角标**（显示条数）。**打开通知页会自动全部标记为已读**，角标随即消失（不用手点）；停留期间新到的通知也会自动标为已读。前端每 3 秒自动检测一次未读数。

## 局域网测试（给同学用）

本机已启动局域网服务，同网段设备直接打开：

```
http://172.17.41.64:8080/
```

- 只支持**同一个局域网/同一个 Wi-Fi**（你电脑网段是 `172.17.40.0/21`，网关 `172.17.40.1`），手机用流量打不开；
- 这是新的访问地址，浏览器里之前的登录状态不通用，**需要重新登录一次**（用 `3806133211@qq.com`）；
- 手机/同学电脑需要能上外网，因为数据在 Supabase（东京）；
- 服务是构建产物（`dist/`），改动代码后要重新构建。

重新启动服务（关掉电脑/重启/DSH 关闭后）：

```powershell
cd campus-forum-app
npm run lan
```

> 为什么不是 `http://172.17.41.64/`？你电脑的 **80 端口被另一个程序占用了**（访问会返回 404，不是我们的服务），所以改用 8080。
> 如果一定要 80 端口，需要管理员权限先查/停那个程序，再做端口转发（`netsh interface portproxy`）。

### 同学打不开时（防火墙）

Windows 防火墙的「专用/公用」配置目前是关闭的，只有「域」配置开着。如果连不上：

1. 把网络位置改成「专用网络」（设置 → 网络和 Internet → 以太网 → 网络配置文件 → 专用）；
2. 或者用**管理员身份**打开 PowerShell 执行一次：

```powershell
netsh advfirewall firewall add rule name="CampusForum-8080" dir=in action=allow protocol=TCP localport=8080
```

## 常见问题

**打开网站提示「数据库还没有初始化」**
→ 说明前端连的不是已经建库的项目。检查 `.env.local` 里的 `VITE_SUPABASE_URL` 是否为 `https://qkdyfrwsiikluyaristy.supabase.co`，改完重启 `npm run dev`。

**同学访问显示「无法访问此网站」**
→ 先确认手机和电脑在同一网络；再按上面「防火墙」一节放行 8080；确认 `npm run lan` 还在运行（终端窗口别关）。

**注册报 `email rate limit exceeded`**
→ 「Confirm email」还开着，按第 2 步关掉即可。

**注册时报错**
→ 看 Supabase Dashboard → Logs → Postgres，把错误发我。

**想让别人也能用这个网站**
→ 需要部署到公网（GitHub Pages / Vercel / Netlify 都可以，本项目是纯静态站点）。
GitHub 目前在你电脑的 hosts 文件里被屏蔽了，解锁后才能用 GitHub Pages；也可以用 Vercel 拖文件夹部署。
这一步需要的话我再帮你做。
